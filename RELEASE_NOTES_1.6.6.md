# LocalScribe 1.6.6

- Add Japanese throughout the interface, menus, and system permission descriptions, with immediate switching in Settings and automatic macOS language selection.
- Add a Japanese README and links between all three README languages.
- Align floating-caption source controls with their heading and give home-screen headings more breathing room.
- Simplify transcription setup: performance and privacy details are available from the information button, while actionable notices and errors remain visible.

Requires macOS 15.5 or later on Apple silicon. Apple SpeechAnalyzer and floating live captions require macOS 26.

The public package uses an ad-hoc integrity signature. It is not Developer ID signed or notarized by Apple.
