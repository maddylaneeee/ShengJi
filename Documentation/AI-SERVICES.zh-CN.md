# 自定义 AI 服务源

[English](AI-SERVICES.md)

声迹 1.7.1 支持用内置 Gemma、本机 LM Studio 或官方 OpenAI、DeepSeek API 对文字稿进行纠错、润色和总结。识别、翻译和音频导出继续使用原有本机引擎。

## 配置步骤

1. 打开设置 → 模型，开启 **使用自定义ai服务源**。配置弹窗立即出现；取消或关闭弹窗后，开关仍保持开启，即使配置尚未完成。
2. 选择 LM Studio、OpenAI 或 DeepSeek。云端地址固定为官方 API。LM Studio 仅接受 `localhost`、`127.0.0.1` 或 `[::1]`，可修改端口，可有 `/v1` 后缀；其他主机、URL 中的凭据和查询参数会被拒绝。
3. 云端输入 API key。LM Studio 若启用了认证，则输入 Token。凭据只保存在本机不参与同步的 Keychain。替换框留空保留已有凭据；需要删除时使用明确的删除选项。
4. 获取模型列表并选择模型，或手动填写模型 ID。列表可能包含非文字模型或尚待加载的模型，请测试连接。应用自动构造请求，无需填写 JSON。
5. 云端生成需要确认发送任务文字稿及可能产生的费用。获取模型列表不发送稿件；测试连接只发送固定合成短句，云端测试可能产生少量费用。
6. 保存。允许缺少 key 或模型时保存配置，但补齐前不能生成。更改草稿会清除旧测试结果；开关开启时始终保留“配置…”入口。

需要自行启动 LM Studio 服务并准备文本模型，声迹不会管理其进程或下载其模型。本版不支持局域网远端地址或任意云端网关。

## Gemma 与失败处理

开启自定义模式后，立即取消声迹的 Gemma 下载并停止它自己启动的 Gemma helper；后续下载、安装提交及进程启动都会被阻止。已安装模型保留，可手动移除。缺少 key、配置未完成、HTTP 错误和模型不可用均不触发回退或模型下载。关闭自定义模式恢复内置使用资格，但不自动恢复旧下载。自定义服务不受 Gemma 低内存开关限制。

同一时刻只允许一个窗口使用 AI，另一窗口会收到忙碌提示。窗口只能取消自己拥有的任务；更改服务配置会取消旧任务，旧进度和结果不会覆盖新任务。应用只终止自己拥有的进程。

所有服务复用受保护的提示词、保守批次、结果校验、预览、撤销和恢复流程。纠错检查片段 ID、数量、非空、长度、数字、链接、邮箱和时间表达，失败片段保留原文。错误 JSON 最多修复一次；网络错误不自动重试。总结沿用现有信息与长度校验，重要内容仍需人工复核。

## 协议与隐私

三个服务均使用 Chat Completions 及模型列表接口。OpenAI 使用 `max_completion_tokens`、`store: false`，避免无条件添加与模型相关的采样参数；DeepSeek 使用 `max_tokens` 并关闭思考模式；LM Studio 使用 `max_tokens` 和确定性温度。不会将 llama.cpp 私有字段发给外部服务。

支持 SSE 与普通 JSON，拒绝工具调用、拒答、非正常结束、空结果和中断的流。不跟随重定向，也不显示服务端任意错误正文。云端仅接收任务需要的文字稿、相邻上下文、受保护系统指令和附加指令，不上传原始音视频。`store: false` 只是 API 选项，不代表对服务商所有数据保留行为作出承诺。LM Studio 接收本机文字，其其他联网行为取决于自身设置。

## 验证边界

OpenAI、DeepSeek 仍为待正式 key 联调的预览功能。自动化测试使用临时假凭据与本地模拟，不调用云端 API。测试覆盖不同服务请求、模型发现、Keychain、地址与跳转限制、鉴权与限流、按字节拆分的中文 SSE、不完整输出、超时、取消、Gemma 下载隔离和原文保护。这些测试不能证明真实模型质量或账户权限。

正式支持前，需用真实 key 和合成短稿分别验证模型发现、连接测试、纠错、总结和取消；也需验证实际 LM Studio 文本模型。不要把 key 或私人稿件写入测试、issue 或报告。

协议参考：[LM Studio](https://lmstudio.ai/docs/developer/openai-compat/chat-completions)、[OpenAI](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/)。
