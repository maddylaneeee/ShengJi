# AI 文稿优化与自定义服务

[English](AI-SERVICES.md)

声迹可在受支持的 Mac 上用 Apple 智能完成本机翻译、纠错润色与总结，另有 Gemma 4 和可选 NLLB 作为本地选择。纠错和总结也可使用同一台 Mac 的 LM Studio 或官方 OpenAI、DeepSeek API。自定义 AI 服务不替换识别、翻译与音频导出的本机引擎。

## AI 文稿优化

完成转录或导入稿件后，打开右侧检查器的“AI 优化”。

- **纠错／润色：** 修正明显识别错误，整理标点、碎句和口头填充词，以实时对照显示；Apple 智能的整理步骤保留有意义的重复和原话用词。未通过校验的片段保留原文。使用 Apple 智能时，会先单独纠正听错的词，再整理标点与碎句，其余用词保持原话；可在提示词框中列出人名、品牌和术语，帮助模型改对。
- **总结：** 用总结替换文字预览，并保留可撤销的原稿快照。
- 可临时指定（最多 500 字）人名、术语、风格、长度、重点或格式；长期提示词通过 `--cli prompts edit` 编辑。AI 输出仍需人工复核。

**Apple 智能：** 在受支持、运行 macOS 26 或更高版本且 Apple 智能已开启、系统模型已就绪的 Mac 上，声迹可使用系统本机模型完成翻译、纠错润色与总结。无需另行下载应用管理的 AI 模型，系统模型由 macOS 准备。Apple Translation 仍是默认翻译服务。翻译以更大的窗口送入模型，并在单次翻译中维护人名、术语与风格词表，让后续窗口保持一致；Apple 智能不支持的语言或无法处理的片段会自动改用 Apple 翻译。长文稿总结会分段累积，每一步都能看到已写出的总结。从旧版本更新且已安装 Gemma 或 NLLB 时，声迹会询问一次是否删除旧模型并切换；选择保留则一切照旧，之后可在“设置 → 模型”中切换。NLLB 仍可作为可选翻译模型下载。不支持 Apple 智能的 Mac 继续使用 Gemma 与 NLLB。

**内置 Gemma 4**（不支持 Apple 智能的 Mac，或选择保留旧模型时）：默认 E2B 模型约 2.8 GB，可在设置中启用约 4.6 GB 的 E4B 模型。模型按需下载，仅在选择 AI 任务后加载，加载前会释放识别与 NLLB 运行环境。8 GB 及以下内存的 Mac 默认关闭，可在设置中手动开启。

**自定义 AI 服务源：** 在“设置 → 模型 → 使用自定义ai服务源”中接入 LM Studio（仅本机回环地址，默认 `http://127.0.0.1:1234/v1`）、OpenAI 或 DeepSeek。开启后取消并禁止 Gemma 下载与加载，不会自动回退；AI 文稿优化优先使用该服务源而非 Apple 智能。OpenAI 和 DeepSeek 为预览功能，经你确认后才发送任务文字，调用可能产生费用。配置步骤见下文。

## 可用条件与限制

- Apple 智能需要 macOS 26 或更高版本、受支持的 Mac，并已开启且系统模型已就绪。macOS 26 路径尚未经过实机验证，开发和实际模型测试使用 macOS 27。
- 系统模型的上下文窗口有限，且可能拒绝部分内容。受影响的翻译片段回退到 Apple Translation，纠错失败的片段保留原文。Apple 智能后来不可用时，App 返回原有模型并显示恢复提示。
- 本地 NLLB 需要至少 4 GB 内存及已下载的模型。使用 Apple 智能时仍可选装 NLLB，并在设置中改用它翻译。
- 云端 AI 需要凭据和同意，可能产生服务商费用。OpenAI 与 DeepSeek 连接器仍为预览功能。翻译、纠错和总结均应复核后使用。

## 配置自定义服务

1. 打开设置 → 模型，开启 **使用自定义ai服务源**。配置弹窗立即出现；取消或关闭弹窗后，开关仍保持开启，即使配置尚未完成。
2. 选择 LM Studio、OpenAI 或 DeepSeek。云端地址固定为官方 API。LM Studio 仅接受 `localhost`、`127.0.0.1` 或 `[::1]`，可修改端口，可有 `/v1` 后缀；其他主机、URL 中的凭据和查询参数会被拒绝。
3. 云端输入 API key。LM Studio 若启用了认证，则输入 Token。凭据只保存在本机不参与同步的 Keychain。替换框留空保留已有凭据；需要删除时使用明确的删除选项。
4. 获取模型列表并选择模型，或手动填写模型 ID。列表可能包含非文字模型或尚待加载的模型，请测试连接。应用自动构造请求，无需填写 JSON。
5. 云端生成需要确认发送任务文字稿及可能产生的费用。获取模型列表不发送稿件；测试连接只发送固定合成短句，云端测试可能产生少量费用。
6. 保存。允许缺少 key 或模型时保存配置，但补齐前不能生成。更改草稿会清除旧测试结果；开关开启时始终保留“配置…”入口。

需要自行启动 LM Studio 服务并准备文本模型，声迹不会管理其进程或下载其模型。本版不支持局域网远端地址或任意云端网关。

## 自定义服务的失败处理

开启自定义模式后，即使这台 Mac 可以使用 Apple 智能，纠错润色与总结也使用自定义服务，不会自动回退到 Apple 智能或 Gemma。

开启自定义模式后，立即取消声迹的 Gemma 下载并停止它自己启动的 Gemma helper；后续下载、安装提交及进程启动都会被阻止。已安装模型保留，可手动移除。缺少 key、配置未完成、HTTP 错误和模型不可用均不触发回退或模型下载。关闭自定义模式恢复内置使用资格，但不自动恢复旧下载。自定义服务不受 Gemma 低内存开关限制。

同一时刻只允许一个窗口使用 AI，另一窗口会收到忙碌提示。窗口只能取消自己拥有的任务；更改服务配置会取消旧任务，旧进度和结果不会覆盖新任务。应用只终止自己拥有的进程。

自定义服务复用受保护的提示词、保守批次、结果校验、预览、撤销和恢复流程。纠错检查片段 ID、数量、非空、长度、数字、链接、邮箱和时间表达，失败片段保留原文。错误 JSON 最多修复一次；网络错误不自动重试。总结沿用现有信息与长度校验，重要内容仍需人工复核。

## 协议与隐私

三个服务均使用 Chat Completions 及模型列表接口。OpenAI 使用 `max_completion_tokens`、`store: false`，避免无条件添加与模型相关的采样参数；DeepSeek 使用 `max_tokens` 并关闭思考模式；LM Studio 使用 `max_tokens` 和确定性温度。不会将 llama.cpp 私有字段发给外部服务。

支持 SSE 与普通 JSON，拒绝工具调用、拒答、非正常结束、空结果和中断的流。不跟随重定向，也不显示服务端任意错误正文。云端仅接收任务需要的文字稿、相邻上下文、受保护系统指令和附加指令，不上传原始音视频。`store: false` 只是 API 选项，不代表对服务商所有数据保留行为作出承诺。LM Studio 接收本机文字，其其他联网行为取决于自身设置。

## 验证边界

OpenAI、DeepSeek 仍为待正式 key 联调的预览功能。自动化测试使用临时假凭据与本地模拟，不调用云端 API。测试覆盖不同服务请求、模型发现、Keychain、地址与跳转限制、鉴权与限流、按字节拆分的中文 SSE、不完整输出、超时、取消、Gemma 下载隔离和原文保护。这些测试不能证明真实模型质量或账户权限。

正式支持前，需用真实 key 和合成短稿分别验证模型发现、连接测试、纠错、总结和取消；也需验证实际 LM Studio 文本模型。不要把 key 或私人稿件写入测试、issue 或报告。
