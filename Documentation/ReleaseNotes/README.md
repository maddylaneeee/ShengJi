## Maintenance

When preparing a new release, move the previous root-level `RELEASE_NOTES_<version>.md` here, update any relative links in it, and add it to this index. Keep the new current version's notes at the repository root and update the current-release link above. Preserve historical wording and version-specific behavior.

Some published releases have no separate notes file tracked in this repository; their notes remain available in the published release history linked above.
