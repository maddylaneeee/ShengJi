# 声迹 1.7.0 Beta

[English](BETA.md) | **简体中文**

声迹 1.7.0 是供人工测试的实验性预发布版本，不会通过正式版的应用内更新通道提供，也不会替代 GitHub 上的最新正式 Release。请仅在能够接受未完成功能并愿意反馈问题时安装。

## 建议重点测试

- 使用本地 Gemma 模型进行转录稿润色和基于原文证据的总结。
- AI 模型自动加载，以及任务成功、失败、取消、超时或退出后可靠卸载。
- AI 结果流式显示、一键撤销、字幕导出同步更新和带行号的文字预览。
- 实验性的光标转写、全局开始/停止快捷键和悬浮状态控制。

## 已知问题：光标转写

**光标转写目前仍然无法可靠正常工作，预览和向目标 App 输入文字都可能出现很大的延迟。请勿将其用于对实时性有要求或重要的输入。** Esc 和 Command-Shift-S 在不同目标 App 中的表现也仍需继续测试。

普通麦克风转录和文件转录使用不同流程，仍是此 Beta 版本中更推荐的转录方式。

## Beta 更新方式

- 正式版声迹使用 GitHub 的最新正式 Release，不会自动收到此预发布版本。
- 此 Beta 暂无独立的自动测试版更新源；后续 Beta 需要从 GitHub Releases 手动下载。
- 覆盖现有安装前，请备份重要转录稿。

## 安装与安全提示

从 `v1.7.0` 预发布页面下载 DMG，打开后将“声迹”拖入“应用程序”。此构建仅使用 ad-hoc 签名，尚未使用 Apple Developer ID 签名或公证。首次启动时，macOS 可能要求在“系统设置 → 隐私与安全性”中点击“仍要打开”。只有在信任本仓库时才应继续。

## 反馈问题

请通过 [GitHub Issues](https://github.com/maddylaneeee/ShengJi/issues) 反馈，并尽量附上 Mac 型号、macOS 版本、识别引擎、光标转写的目标 App、复现步骤和完整错误信息。
